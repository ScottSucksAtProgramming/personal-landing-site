title: Medic Time
kind: ems
summary: Hands-free app that logs and timestamps events during an EMS call.
stack: Swift, iOS, watchOS (Android planned)
status: in development
order: 3
---

On a critical call, every intervention needs a time: when the epi went in, when the rhythm changed, when you left the scene. Those times end up on gloves, tape and memory, and the chart is only as good as what survives the ride.

Medic Time logs each event the moment it happens, so the timeline is already built when it's time to document. Gloved hands are busy, so it takes input however the moment allows:

- **Voice commands**, so you never have to touch the phone.
- **An Apple Watch companion**, one tap on the wrist.
- **Widgets**, for logging from the lock screen or home screen.
- **Big in-app buttons**, when the phone is already out.

It's iOS only for now, built in Swift, with Android planned. The source will go public once it's further along.
